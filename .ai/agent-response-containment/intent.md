# Automatic response containment
goal: 매니저가 중지한 자동 응대가 신규 등록·예약 작업으로 다시 시작되지 않는다.
scope: 재개 전 차단 보강. 실제 파일럿 활성화와 실문자 검수는 별도 승인 대상.
must:
  - 빈 설정·구형 전체 자동 설정은 OFF로 처리한다.
  - 검수는 테스트 계정 1명, 선택한 실공고, 최대 20분의 새 인입에 한정한다.
  - 대화에 범위 밖 공고 또는 검수 시작 전 미응답이 섞이면 자동 처리하지 않는다.
  - 수신거부 저장과 매니저 직접 발송은 유지한다.
must_not: 운영 AI 활성화, 실문자 발송, 수동 중지 해제, 과거 큐 재처리.
