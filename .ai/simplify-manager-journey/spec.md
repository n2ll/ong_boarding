# 단순화 명세
flow:
  - 오늘 할 일 → 급한 업무 및 실제 미처리 목록 → 해당 대화/모집으로 이동.
  - 모집 → 배송 정보 입력/초안 → 공고 내용·노출 요약 확인 → 기존 등록 확인.
  - 지원자 대화 → 문자/통화 → 처리 완료 또는 공고별 일정·결과 기록.
  - 인력풀 → 사람의 이력·가용성 확인 → 모집 또는 대화로 연결.
boundaries:
  - 메뉴는 네 업무 목적지 + 관리(응대 설정·외부 인력·화주사·환경설정).
  - 좁은 데스크톱의 작업 공간은 보존하고 아이콘 밑에 짧은 라벨을 추가한다.
  - 미해결/조회 실패/운영 차단은 접히는 통계로 이동하지 않는다.
  - 모집 대상 상세를 접어도 추천 조건과 실제 노출 결과를 확인할 수 있어야 한다.
  - 지원자 화면·AI 응대 정책·정산·배정 로직은 이번 변경 범위 밖.
data: 스키마와 API 변경 없음. 메뉴 메타데이터 및 표시 상태만 변경.
failure:
  - 조회 실패 → 기존 재시도·안전 경고 유지. 0건으로 오인하지 않는다.
  - 작성 중 메뉴 이동 → 기존 저장되지 않은 변경 확인 유지.
verification:
  - 메뉴 목적지/보조 경로/딥링크 테스트, 빌드.
  - 합성 데이터의 홈·모집 모달·관리 메뉴를 데스크톱/모바일에서 검수.
