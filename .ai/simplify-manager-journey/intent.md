# 관리자 사용자 여정 단순화
goal: 관리자가 메뉴·설정 구조를 배우지 않고 모집 → 대화 → 일정·결과 기록을 진행한다.
trigger: 실제 사용자가 필요한 인원 입력과 결과 기록 위치를 찾기 어렵고 화면 전반이 복잡하다고 피드백.
users: [배송 대행 조직 관리자, 채용팀]
must:
  - 오늘 할 일 / 모집 / 지원자 대화 / 인력풀의 네 목적지를 모든 화면 크기에서 읽을 수 있다.
  - 홈은 지금 처리할 일, 공고 작성은 필수 정보와 노출 대상 요약부터 보여준다.
  - 설정·통계·선택 입력은 필요할 때 열되 오류·운영 차단·노출 0명 경고를 숨기지 않는다.
must_not:
  - 자동 발송·확정·운영 설정·DB 구조를 변경하지 않는다.
  - 기존 딥링크·작성 중 이탈 보호·공고 확인 단계를 제거하지 않는다.
decisions:
  - 기존 색상·서체를 유지하고 정보 위계와 탐색 규칙부터 개선한다.
  - 실제 지원자 데이터/문자를 변경하지 않고 로컬 합성 데이터로 검수한다.
success:
  - 노트북과 휴대폰에서 메뉴 이름과 다음 행동이 보이고 보조 화면도 접근 가능하다.
  - 공고 작성·대상 수정·대화 처리 흐름이 기존 안전 조건을 유지한다.
