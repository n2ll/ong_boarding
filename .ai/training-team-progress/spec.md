# 동작 명세

- 응대: 단순 관심/교육비 질문/짧은 긍정을 강한 선탑 의사로 단정하지 않는다. 목적→의사→약 2시간과 열린 가능 날짜/시간 질문. 이미 답한 내용 재질문 금지. 구체 일정은 실제 교육라인 첫 상차지·연결 프로 기준, 담당자 조율 전 확약 금지.
- 운영 사실: 공고 50/51/52에 통상 09–10시 전후이나 라인별 상이, 노출 운행시간과 대체로 비슷함을 보완. 강남 08:20 같은 예외를 덮지 않는다. 기존 교육비/백업 선택/정산 정책 유지.
- 데이터: 기존 staffing_preparation pool_events에 training(status, backup_intent, scheduled_at, first_loading_location, linked_pro), actor(account_id/name), request_key 추가. 과거 기록 기본값=선탑 미검토/의사 미확인. 이력 append-only.
- 공유 계정: 서버가 계정 ID를 기록한다. 사람이 입력한 작성자는 인증된 실명처럼 표현하지 않고 브라우저에 한 번 기억한다.
- 경합: job/applicant/base_event_id의 결정적 action_key와 기존 UNIQUE로 같은 기준 버전의 동시 저장 하나만 허용. 동일 요청 재시도는 동일 결과, 다른 내용 재사용/새 기준 충돌은 409. 최신 내용 확인 후 재저장.
- 실패: 읽기/저장 오류를 완료로 표시하지 않는다. 잘못된 예정 시각/누락 작성자 거부. 문자/지원자 stage 변경 없음.
- 롤백: 코드 PR revert. 신규 meta는 기존 조회에 무해하게 남김. 운영 공고는 적용 전 사본과 해당 변경 시각을 비교해 변경 필드만 복원; 후보/문자 데이터 수정 금지.
- 자유 응답의 선탑 날짜 질문은 교육 사실/지원자 가능시간 근거와 비교하며 백업 시작일이나 과거 AI 제안은 근거로 쓰지 않는다. 미정·대기중이라는 상태 메모를 선탑 가능시간 또는 수집 완료로 취급하지 않는다.
