# 동작
- KST 다음 날부터 선탑 지정일(예정/완료 상태)과 관리자가 확정한 백업 날짜의 미기록을 조회한다. 종료 시간은 없으므로 당일 알림 없음.
- 같은 공고·후보의 수동 할 일과 하나의 행으로 합친다. 원래 연락 예정일은 따로 보여주고, 가장 이른 확인 필요 날짜로 정렬한다. 수동 할 일 완료는 결과 기록과 별개.
- 홈 ‘오늘 후속 연락·결과 확인’ → 해당 공고 후보의 실제 참여 화면. 명시적 참여 추가/미참여 기록/일정 수정 경로. 자동 저장 없음.
- 기존 records는 실제 참여 전용. optional non_participations(kind/date/note)를 별도 저장하고 실제 참여와 같은 kind/date 중복 금지. 변경 이력·동시 수정·이전 클라이언트 보호 유지.
- 다른 공고의 참여나 선탑 상태만으로 실제 참여를 추정하지 않는다. 미참여 기록도 기존 확정 계획을 제거하지 않는다.
- 조회 실패/손상은 불완전 안내. 운영 DB 마이그레이션 없음. 배포 롤백 시 새 기록의 보존 여부를 확인해야 하므로 구버전 쓰기 금지.
# 검증
- 날짜 경계, 명시적 일정, 복수 공고·날짜, 최신 스냅샷, 결과 보존/충돌 회귀.
- 합성 브라우저 홈→직접 결과 기록→집계 갱신, 미참여, 모바일. 실제 SMS/DB 쓰기 없음.
