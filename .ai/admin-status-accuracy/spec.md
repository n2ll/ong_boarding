# 관리자 상태 표시 spec
flow:
  - 유효한 제한 세션 → 두뇌·지원자 운영·공고·자동화 요약과 상담 배너에 검수 범위 표시.
  - 해당 지원자 → 검수 대상 표시; 다른 지원자 → 해당 지원자 중지 표시.
  - 검수 중단 → 검수 종료 확인과 완료 안내.
  - 지원자 목록 → 최근 inbound 메시지와 기존 ping_reply 중 최신 시각 표시.
boundaries:
  - 기존 발송 권한, 수동 개입·수신거부 우선순위 유지.
  - 만료·환경 강제 중지·조회 실패 시 검수 진행으로 표시하지 않는다.
data:
  - summary API에서 요청 지원자의 inbound 메시지 시각만 페이지 끝까지 조회.
  - 캠페인 답장 이벤트는 기존 기록 호환용으로 유지; outbound는 답장 시각에 불포함.
failure:
  - 메시지 조회 실패 → 기존 목록 오류 처리로 전달; 부분 결과를 정상 응답하지 않는다.
verification:
  - 모드 표시 단위 테스트, summary API 페이지 경계·오류·수신/발신 회귀 테스트.
  - 로컬 브라우저 fixture로 상담 배너·두뇌 상태·중단 확인 검증; 운영 발송 없음.
