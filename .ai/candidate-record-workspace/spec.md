# 동작
- 상세의 세 화면 이동 링크를 한 ‘연락·선탑·투입 기록’ 버튼으로 합친다.
- 같은 화면 위에서 기존 공고별 기록 편집기를 연다. 조회 오류/후보 누락은 빈 폼으로 대체하지 않는다.
- 대화 탭에서도 선택 공고가 일반 배송 공고이면 같은 버튼을 제공한다. 표시 기준 공고가 없으면 임의 공고를 선택하지 않는다.
- 저장하거나 닫으면 기존 지원자/대화 화면을 유지한다. 단, Live 현재 큐에서 이미 처리되어 사라진 후보는 저장/닫기 후 기존 다음 후보 자동 이동을 따른다. 기록창 내부 항목 전환은 기존 초안을 유지한다.
- 공고별 기록 편집기에서 연 대화창은 다시 같은 기록창을 중첩해서 열지 않는다.
- 기존 공고 화면의 편집기와 딥링크 동작은 보존한다.
- 인력풀 공통 선탑 이력은 별도 표기/저장 유지. 현재 공고가 마감/중단이면 새 확정 제한 유지.
