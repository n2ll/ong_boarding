# 동작과 데이터
- 새 수요 입력은 운행함·필요 1명을 제시한다. 기록된 수요/운행 없음/명시적 미정은 유지. 예비는 권장 1명이며 부족 인원 계산에 포함하지 않는다.
- 후보 패널은 기본 펼침. 처음 5명만 표시하고 더 보기 제공, 검색은 전체 후보 대상. 이름 검색과 연락/기록은 앞에, 날짜 비교·추가 필터는 접는다. 충원판에서 날짜를 선택해 온 경우 날짜 비교를 펼친다.
- raw memo: 기존 staffing event meta.manager_note={text,reference_date}. 팀 공통 메모와 분리, 이벤트별 원문 보존. history에서 원문/기준일/작성자 조회.
- AI 제안 저장 시 선택한 필드와 원문을 한 번에 저장. AI 생략/실패/모든 항목 해제 시에도 메모만 저장 가능.
- 메모만 저장은 기존 structured draft를 바꾸지 않음. 직접 입력으로 바꾼 뒤 저장해도 원문 함께 보존.
- 동일 요청 재시도는 manager_note까지 같아야 중복 처리. 충돌 시 원문/검토초안 유지. 원문은 지원자 응대 프롬프트로 전달하지 않음.
- 명시적 선탑 완료는 완료상태와 실제참여 제안 누락을 보완하되, 선택해제 가능. 예정/희망/부정은 완료 아님.
