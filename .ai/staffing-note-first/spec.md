# 동작

- 후보 상세·대화·일반 진행 기록은 메모로 열린다. 명시적인 `record_mode`와 후속 업무 링크는 기존 직접 입력으로 열린다.
- 오늘 기준일은 요약하고 변경할 때만 펼친다. 오늘이 아닌 기준일은 항상 입력값을 보여준다.
- AI 정리는 버튼으로만 요청한다. 제안값·기존값·근거·확인 질문을 보여주고 선택 후 저장한다.
- 메모만 저장은 기존 서버 기록을 유지한다. 직접 입력한 미저장 변경이 있으면 제외 여부를 확인한다. 취소 시 입력을 유지한다.
- 버전 충돌·저장 실패·미저장 보호·투입 확정 확인은 유지한다.

검증: 기존 메모 파싱/API 및 기록 진입 테스트, 범위 lint/build, 가상 데이터 브라우저에서 기본 진입·직접 입력·메모 단독 저장·AI 검토·모바일 확인.
