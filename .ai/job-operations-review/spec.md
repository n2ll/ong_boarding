# 동작
- 기존 공고 생성 한 번으로 본문의 `[운행 안내]` 단락에 명시된 운행 조건을 모은다. 모델·호출 수·DB·응대 설정 변경 없음.
- 상차 순서, 배송 시간, 수거 방식·가방 기준일, 반납 장소·기한, 요일별 예외를 원문대로 보존. 맞수거에서 전날 가방/당일 반납/모든 배송지 수거를 추정하지 않는다.
- 단락이 하나이며 구역 밖에 상차·수거·반납·운행 시각이 없을 때만 간단 편집기를 제공하고, 입력은 기존 공고 본문에 직접 반영한다. 중복 가능성이 있으면 전체 원문 편집과 안내를 표시한다. 별도 상태/권위값 없음.
- 생성 당시 원문은 전체 편집 폴백에서도 접어서 비교할 수 있게 한다. 현재 원문 수정 시 기존 생성 기준 변경 안내를 유지.
- 직접 작성·기존 복제처럼 단락이 없거나 여러 개인 본문은 기존 전체 편집기를 사용한다. 임의 구조화/덮어쓰기 없음.
- 본문 자동 저장·이어쓰기·등록·AI 수거 응대 경로를 재사용한다. 문자 초안은 별개이며 본문 변경 뒤 발송 전에 검토한다.
- 실패/복구: 생성 실패는 기존 명시된 오프라인 폴백, 단락 미식별은 전체 본문 편집. 코드 revert로 복구하며 운영 데이터 변경 없음.

- 모델 실측에서 상세 주소가 반납 기한과 합쳐져 상담 근거에서 탈락함을 발견. tool body 설명에도 분리 예시를 넣고 편집 도움말에 줄 분리를 안내한다. 생성은 초안이며 관리자가 원문과 대조한다.
