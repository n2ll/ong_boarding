# Spec
- 기존 인재풀 화면: 배송 희망 전체/정기/백업/미등록 필터 + 지역·시간·차량·사전 연락 원문 검색. 둘 다는 정기·백업 양쪽에 포함한다.
- 최신 pool_preferences 이벤트만 사용한다. 같은 시각은 id 내림차순. 최신 데이터가 손상되면 과거 조건으로 되돌리지 않는다.
- 기존 반응 요약 배치 API를 재사용한다. 조회가 불완전하면 희망 조건 필터 결과와 선택을 차단하고 재시도를 제공한다.
- 조건 저장/복원/초기화/선택 해제에 새 필터를 포함한다. 기존 추천은 좁혀진 결과에서 실행하고 근거 점수는 유지한다.
- 원문과 저장일을 이름 아래에 표시한다. 미등록은 거절·부적합이 아니다. 자유 문장으로 확정 차량/가용성/근무 배정을 추론하지 않는다.
- DB 마이그레이션, 노출 정책·동의·자동 응대 설정 변경 없음. 롤백은 코드 되돌리기; 기존 희망 이벤트 보존.
