# 명세
- 오늘 또는 이후 날짜를 선택하면 기존 후보 패널에서 ‘대체 후보 비교’ 창을 열 수 있다.
- 같은 날짜 최신 유효 관리자 기록의 확정자 한 명을 결원 가정 대상으로 선택한다. 다른 날짜/손상/미확정 후보는 대상이 아니다.
- 기존 날짜별 연락 순서로 미확정 대안 3명을 비교하고 더 볼 수 있다. 선택자·다른 확정자·불가·보류·거절·진행 중단은 대안에서 제외하되 기존 전체 목록을 유지한다.
- 가용성/차량 미확인은 확인 필요로 남긴다. 선탑 상태, 본인 의사, 날짜 역할, 차량, 해당 공고 실제 참여, 다른 라인 본담당 후보, 마지막 연락·다음 할 일을 동일 항목으로 비교한다.
- 손상 최신 기록은 과거 이력으로 대체하지 않는다. 타 공고 조회 불완전은 경고하며 충돌 없음을 단정하지 않는다. 다른 본담당 후보는 시간 충돌/배정 확정이 아니다.
- 날짜/공고 변경·새 조회 시 가정을 초기화한다. 기록 수정·대화는 기존 경로로 연결한다. 가정 선택 자체는 저장·통지하지 않는다. 수요가 없으므로 부족 인원도 추정하지 않는다.
- 복구: 코드 revert. 검수는 합성 데이터만 사용한다.
