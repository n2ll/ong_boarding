# 수요 일괄 입력 명세
flow:
  - 날짜별 충원판 → 여러 날짜 입력 → 라인·날짜 선택 → 운행함(기본 1명) / 운행 없음 → 범위 요약 → 저장 결과
  - 선택 날짜는 현재 충원판의 최대 7일 범위. 미선택 날짜는 변경하지 않는다.
  - 기존 수요 기록(명시적 미정·손상 포함)은 유지하고 개별 수정으로 안내한다.
  - 확정 인원 초과·손상 기록·중복 확정은 저장 전 경고, 확정 기록은 변경하지 않는다.
data:
  - 기존 POST /api/admin/jobs/[id]/staffing-demand 재사용, DB 변경 없음
  - 대상별 base_event_id:null + 고정 action_key, 최대 3개 동시 요청
failure:
  - 일부 실패해도 저장 성공은 유지. 실패만 동일한 내용·키로 재시도
  - 409는 확인 필요로 남기고 자동 덮어쓰기·재시도 금지
  - 시작 후 폼 고정, 닫기 전 실패/입력 손실 안내, 저장 중 닫기 금지
  - 저장 시도 후 충원판·홈 갱신. 통신 실패는 미저장으로 단정하지 않음
verification: 핵심 선택·보존·재시도 테스트, 기존 API 검사, 타입·빌드, 로컬 가상 데이터 모바일 QA
