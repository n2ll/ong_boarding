# Evaluation
- 연결/관심·배차 준비 helper/API: 관련 23개 검사 통과. 잘못된 날짜, 범위 밖 후보, 최신 손상 기록, 요청 재시도·중복·키 충돌, 페이지 조회 실패 포함.
- 번호 상담: 신규 실패 재현 후 focused 75개 및 기존 단계/노출/관찰저장/라우팅 72개 통과. 과거 대량 안내는 상담 앵커로 쓰지 않으며 번호를 현재 허용 공고에만 연결한다.
- 실제 발송 안내를 메모리 GET fixture로 재생하여 3개 번호 매핑, 선택한 두 공고의 가능 시간 관찰, stage stay 확인. 개인정보와 운영 원문은 저장소에 보관하지 않았다.
- `npx playwright test --config=playwright.operations.config.ts`: 1개 흐름 통과. 연결 후보 50명/관심 0명 구분, 저장 실패 후 같은 action_key 재시도, 역할 제약, 후보 재조회 실패 중 편집 유지, 390px 편집/고정 저장 버튼, 변경 버리기 확인 포함. 외부 API와 모든 미승인 쓰기 요청 차단.
- 브라우저 테스트 초기 실패는 테스트의 실제 버튼명 불일치였으며 수정 후 통과. PC/모바일 스크린샷 직접 확인.
- Haiku 실제 호출 1회 검수는 자동 승인 검토가 내부 공고·응답 문맥의 외부 전송 승인 부족으로 거절하여 실행하지 않았다. 위 결과는 로컬 동작 검증이며 실제 모델의 응답 성공을 의미하지 않는다.
- 실제 수신 1건이 원문 검증에서 중단된 사실을 확인했다. 당시 raw 모델 출력이 없어 문자 ID 오류인지 인용 변형인지 확정할 수 없다. 진단을 분리했으며 기존 중지 상태는 변경하지 않았다.
- `npm run build`: 종료 코드 0. 새 경로 포함 컴파일·린트·타입 검사 통과. 기존 job-audience-preview 테스트의 module 변수 경고 2건만 유지.
