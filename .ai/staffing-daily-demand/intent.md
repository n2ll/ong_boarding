# 날짜별 실제 배송 수요
goal: 관리자가 라인별 운행 여부와 필요 인원을 날짜별로 입력해 실제 부족 인원을 판단한다.
trigger: 기존 충원판은 공고 모집인원을 모든 날짜에 반복해 예비 모집을 실제 결원처럼 표시한다.
must:
  - 미정 / 운행 없음 / 운행·필요 인원 구분
  - 날짜별 수요와 확정·예비 후보를 한 화면에서 비교
  - 동료 수정과 재시도에서 기록 유실 방지
must_not:
  - 수요 입력으로 후보 확정·취소, 문자 발송, AI 설정 변경
  - 미정 수요를 0명이나 확정된 결원으로 해석
success: PC·모바일에서 날짜 1건을 수정하고 해당 셀만 새 수요로 계산한다. 다른 날짜와 후보 기록은 보존한다.
