# 명세
- 기존 노출/유효 후보/최신 스냅샷 범위에서 scheduled 상태의 scheduled_at과 서버 기준 upcoming/elapsed를 전달한다. 다른 상태의 잔존 일시는 제외한다.
- 미완료 후속 업무의 기한 상태만 전달한다. 실제 기한/메모/연락 결과/연결 프로는 전달하지 않는다. 내부 기한은 지원자와 약속한 연락일이 아니다.
- 상담 전용 answers.fields에 ‘개별 선탑 일정’을 추가한다. 공고 일반 교육 조건과 분리한다. 모델 자유 답변 대신 서버가 해당 공고의 관리자 일시로 답한다.
- 미래 예정 일시 확인은 stay. 지난 시각, 일시 없음/현재 상태 불일치, 마감 공고, 취소·변경 요청은 handoff. 지난 시각만으로 완료 처리하지 않는다. 완료 기록 뒤 이전 일정 재사용 금지.
- 문의 없이 개인 일시를 덧붙이지 않는다. 일반 교육 목적/소요/교육비는 기존 원문 안내. 후보 상태/기록/확정은 상담으로 바꾸지 않는다.
- 데이터 마이그레이션/새 UI 없음. 자유문장 메모의 약속 추출은 자동 발송 근거로 사용하지 않는다.
실패: 최신 기록 조회/검증 실패는 기존 자동 응대 보류. 누락 기록은 매니저 확인.
복구: 코드 revert, 기록/운영 AI 설정 변경 없음.
검증: loader와 실제 서버 응답의 핵심 RED→GREEN, 기존 상담/재질문 관련 회귀, 타입/빌드, 가상 Haiku 소수 평가.
