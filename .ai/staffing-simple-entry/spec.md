# 동작
- 충원판의 필요 인원 입력 → 숫자 입력 → 저장. 숫자를 입력하면 운행 수요로 설정한다.
- 미정/운행 없음은 처음부터 보이는 선택지. 기존 미정을 공고 모집인원으로 자동 확정하지 않는다.
- 후보의 진행 기록 → 연락·할 일(기본) / 선탑 진행 / 실제 참여 / 투입 날짜 선택.
- 섹션 이동은 같은 초안을 유지한다. 투입 날짜를 명시적으로 열기 전에는 비교 날짜를 자동 추가하지 않는다.
- 전체 초안 저장과 기존 검증·동시 수정 충돌·확정 확인을 유지한다. 화면 밖의 값도 지우지 않는다.
- 저장 실패 시 입력 유지. 가상 데이터 PC/모바일 E2E로 숫자 바로 입력, 섹션 이동과 기존 기록 보존 확인.
- API·DB·모델 변경 없음. 운영 상태·실제 수요를 추정 입력하지 않는다.
