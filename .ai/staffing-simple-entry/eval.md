# 검증
- `npm run build` 성공 (consultation Playwright 설정의 production webServer 빌드).
- `npx tsc --noEmit`, `git diff --check` 통과.
- 수요·충원판·연락 후속·실제 참여·대화 복귀 기존 E2E 10건 통과.
- 신규 진행 기록 E2E 1280px/390px 2건 통과. 섹션 이동 후 초안 유지, 저장 시 기존 확정·선탑 정보·참여 이력 보존, 명시적 날짜 편집 전 자동 추가 없음, 삭제한 날짜 재추가 방지, 다른 섹션의 유효성 오류로 복귀 확인.
- 초기 신규 검수 실패는 중첩 label의 정확한 텍스트 매칭 문제였다. 접근성 스냅샷에서 실제 값 보존을 확인하고 textbox/combobox 역할 선택자로 수정 후 통과.
- PC/모바일 필요 인원·선탑 화면 캡처 확인. 가로 넘침 없음, 저장 버튼 유지.
- 모든 브라우저 검수는 로컬 인증 fixture/API mock. 실제 수요·지원자 기록·문자·응대 설정 변경 없음.
- 범위: 입력 화면 1차 단순화. 자유문 메모 자동 구조화나 전체 후보 화면 재설계는 포함하지 않는다.
