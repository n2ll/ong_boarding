# 동작
- 후보의 ‘메모로 기록’ → 메모/기준일 입력 → Haiku 4.5 1회 호출 → 항목별 기존 값/제안 검토·선택 → 기존 기록 API로 저장.
- 지원 범위: 연락 결과, 선탑 가능 시간·진행 상태(일정 조율/완료/보류), 본인 백업 의사, 다음 할 일/기한, 실제 선탑·백업 참여 추가. 날짜별 배차·투입 확정·상세 접선 정보는 직접 기록에서 관리한다.
- 생성 API: 검증된 관리자·공고/후보 연결 확인. 1000자 메모와 공고 제목/기준일만 전송. 운영 기록 쓰기 없음, 사용량만 적재.
- 모델 출력은 허용 필드/길이/실제 날짜/원문 근거를 검증. 미정 정보는 questions로 반환하며 저장 필드와 분리.
- 선택 항목만 기존 초안에 병합. 메모·확정·다른 항목·이력 보존. 실제 참여 중복 방지. 저장 충돌/재시도는 기존 API 이용.
- 메모/기준일 변경 시 이전 제안을 무효화. 실패/대화 이동 시 입력 보존. 닫기 시 미저장 안내.
- 검수: 순수 병합/검증·API 인증/실패 테스트, 로컬 가상 데이터 PC/모바일 메모→검토→저장. 실제 사람에게 발송 없음.
