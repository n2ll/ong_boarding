## 원인 및 보완

4번 응답은 HTTP 200, `stop_reason=tool_use`, 출력 289토큰이었다. 근거는 원문과 일치했으나 다음 구조가 잘못되었다.

```json
{"field":"next_action","value":"다시 전화","evidence":"내일 다시 전화하기로 함","due_date":"2026-09-13"}
```

프롬프트에 각 change는 field/value/evidence 세 키만 가지며 기한은 독립된 change라는 예시를 추가했다. parser는 완화하지 않았다. 5번에서는 다음처럼 정상 출력되었다.

```json
[
  {"field":"next_action","value":"다시 전화","evidence":"내일 다시 전화하기로 함"},
  {"field":"due_date","value":"2026-09-13","evidence":"내일 다시 전화하기로 함"}
]
```

최종 API/core 단위 검수 21/21 통과. 잘못된 중첩 키는 계속 거부하며 `npx tsc --noEmit --incremental false`도 통과했다.
