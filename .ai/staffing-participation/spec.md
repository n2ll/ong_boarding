# 동작 및 경계
- staffing_preparation.records에 관리자 확인 실제 참여(id, training|backup, 일자, 메모)를 여러 건 저장. 기존 기록의 누락 필드는 빈 배열로 해석한다.
- 예정/가용성/후보 역할과 실제 참여는 독립적이다. 저장 시 자동 배정·확정·문자·정산을 수행하지 않는다. 미래 일자는 실제 이력으로 받지 않는다.
- 기존 append-only 변경 이력·작성자·낙관적 동시성·중복 요청 보호를 재사용한다. 삭제/정정도 이전 버전이 남는다. DB 마이그레이션은 필요 없다.
- 활성 제한 운영에 동일 범위 기간 연장을 추가한다. 최초 시작·대상·공고를 유지하고 renewed_at부터 최대 14일까지 허용한다. 기존 세션은 24시간 제한을 유지한다.
- 종료된 세션은 소급 연장할 수 없다. expected_updated_at CAS로 다른 관리자의 중단을 덮어쓰지 않는다. 개별 paused 후보는 건드리지 않는다.
- 운영 적용: 사용자 승인으로 기존 지역 문의 1건만 처리하고 기존 범위를 14일 연장한다. 추가 모집 문자는 보내지 않는다.
# 실패 및 복구
- 응답 발송 불확실 시 재발송하지 않고 messages/처리 상태를 확인한다.
- 참여 저장 실패/동시 수정은 초안을 보존하고 재확인을 요구한다.
- 연장 실패/불일치는 현재 설정을 그대로 두고 다시 읽는다. 긴급 중단은 기존 off 동작을 사용한다.
