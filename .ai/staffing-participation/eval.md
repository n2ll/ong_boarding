# 검증
- 결정론: 참여 모델·API/구버전 화면 보호·선탑 진행·운영 기간 파서/API·명단/상위 패널 회귀 81건 통과.
- 브라우저: `playwright.consultation.config.ts`의 참여 이력·파일럿 관리자 경로 1280/390px 4건 통과. 추가·미래일 차단·저장·수정·삭제/이전 이력·동일 범위 연장·중단 확인. 외부 요청/문자 차단한 가상 데이터만 사용.
- 최초 E2E는 인증 fixture 토큰 불일치로 로그인으로 이동해 실패. 두 테스트 토큰을 기존 fixture 값으로 맞춘 뒤 동일 production build를 재사용해 통과했다.
- build: 전용 E2E 서버의 `npm run build` 완료 후 `next start`로 검수. 타입 검사 및 diff 검토 수행.
- 교차 검토: 연장은 대상/공고/최초 시작 보존, paused 쓰기 없음, 만료·강제중지 차단 및 중단 CAS 확인.
# 운영 처리
- 사용자 승인 지역 문의 1건: 자동 처리 시 지역 원문/선호 검증에서 발송 차단. 실제 모델 응답 값은 로그에 없어 원인을 단정하지 않는다.
- 원문 근거 희망 지역을 저장하고 관리자 UI로 안내 1건 발송. 발송 상태 sent·요청 recorded/reconcile matched 및 수동 해결 기록 확인. 보호 대상 paused 유지.
- 추가 모델 재현은 문의 원문의 추가 외부 전송에 대한 자동 승인 검토 거절로 미실행. 별도 승인 질문 대기. 이 변경은 해당 AI 문제의 해결을 주장하지 않는다.
- 배송가방 수거 문의는 사실 확인이 필요한 기존 운영 업무라 미분류 목록에 보존하고 관리자에게 알림. 수거일을 임의 답하지 않는다.
- 실제 업무 전 참여 이력을 임의 생성하지 않음. 프로덕션 배포 및 동일 범위 14일 연장 적용은 별도 읽기 검증 후 결과 보고.
