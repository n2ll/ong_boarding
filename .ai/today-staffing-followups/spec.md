# 동작
- Dashboard → 오늘 후속 연락 → 공고별 후보 연락·할 일 편집 → 기존 저장 경로 → 집계 갱신.
- API: GET /api/admin/staffing-follow-ups. 기존 관리자 인증·서비스 클라이언트 사용.
- pool_events의 applicant/job별 최신 staffing_preparation부터 선택·검증 후 open 업무만 반환.
- 완료/삭제/손상된 최신 기록에서 이전 업무를 되살리지 않음. 기존 후보 연결 필수.
- 시스템·검수 공고 제외. 마감·중단 여부로 명시적 할 일을 제거하지 않음.
- 전송: 이름, 공고, 다음 할 일, 담당자, 예정일, 식별자만. 원문/전화/전체 이력 제외.
- 조회 실패는 재시도, 손상된 기록은 불완전 안내. 대상 누락 시 빈 편집창을 열지 않음.
- 검증: 최신 스냅샷/복수 공고/누락/날짜 정렬 결정론 테스트, 브라우저 가상 데이터 PC·모바일·딥링크, 빌드.
