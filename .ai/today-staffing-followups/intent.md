# 오늘 후속 연락
goal: 관리자가 공고를 하나씩 열지 않고 연락할 후보를 찾아 기록을 이어간다.
trigger: 승인한 순차 개선의 4단계, 공고별 후속 업무가 흩어져 있음.
must:
  - 기존 관리자가 저장한 다음 할 일만 최신 기록 기준으로 집계
  - 오늘·기한 경과 우선, 미래·예정일 미정도 조회 가능
  - 후보와 공고를 함께 식별하고 해당 연락·기록 화면으로 연결
must_not: [자동 발송, 운영 데이터 검수용 수정, 새로운 AI 호출, 별도 업무 저장체계]
decisions:
  - 마감 공고·중단 후보도 명시적으로 남긴 후속 업무를 숨기지 않는다.
  - 계정 전체 공고 기준임을 표시한다.
