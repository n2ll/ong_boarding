# spec
- 기존 전역 제어 행에 제한된 test 세션 저장: 단일 지원자, 시작·만료 시각(20분). 기존 off/auto/draft 계약 보존.
- 관리자 인증 API에서 전화번호가 정확히 일치하는 테스트 이름의 기존 계정만 시작 가능. 환경 강제 중지 시 거절.
- 대상 식별·신규 인입 시각을 모두 제공한 webhook/router만 test 세션의 auto를 받을 수 있다. 대상 없는 호출(예약 작업)은 off.
- 만료·중지·조회 실패·손상값·다른 지원자·세션 시작 이전 메시지는 off. 공유 캐시는 모드 판정 결과 대신 원문만 저장.
- 후보 보류/수신거부/공고 마감 등 기존 정책 유지. 모델 이후 발송/상태 적용 직전에 모드 재확인.
- 관리자 화면에 제한 검수와 만료 시각 표시; 완전 중지 선택으로 세션 해제.
- 검수용 공고는 기존 테스트 계정에게만 노출. 실제 공고 데이터 변경 금지.
- 실패 시 재발송하지 않고 원장 확인. 완료/실패 시 세션 off 및 검수 후보/공고 정리, 실제 이력 보존.
- 전체 AI를 무제한 auto로 켜는 대체 실행은 하지 않는다.
- 실검수에서 발견한 과거 발언 혼입: 상담 프롬프트는 참고용 과거 대화 뒤에 이번 미응답 묶음을 둔다. 미응답 문자는 ID/원문/시각을 보존해 한 번만 전달한다. 과거 인용문을 새 메시지 ID에 붙여도 기존 검증으로 전체 발송·관찰을 차단한다.
- 모델 호출 추가·원문 검증 완화·자동 재시도는 하지 않는다. 실패 모델 출력은 개인정보 없는 가상 평가에서 확인한다.
