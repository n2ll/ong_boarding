# 명세
- 각 홈 후속 연락 행에 ‘최근 진행 보기’를 제공한다. 기본 접힘, 한 번에 한 후보만 펼친다.
- 펼칠 때 기존 해당 공고 staffing-preparation GET을 조회하고 정확한 applicant_id의 최신 snapshot만 사용한다. 기존 SWR로 동일 공고 요청을 공유한다.
- 최근 연락·관리자 선탑 상태/일정·실제 참여와 미참여·현재 팀 메모·기준일이 있는 최근 원문 메모를 구분한다. 담당자/작성자도 구분한다.
- 훼손/누락 기록은 과거 상태로 대체하지 않는다. 재조회 실패 시 이전 데이터임을 표시하고 재시도를 제공한다.
- 상세 기록은 기존 편집 버튼으로 연결. 조회 외 행동 없음. 새 API·DB·응대 모델 변경 없음.
- 검증: 가상 후보/복수 공고로 지연 조회·공고 격리·실패/재시도·손상 최신 기록·390px 표시, 기존 회귀 및 빌드.
