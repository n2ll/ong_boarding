# 명세
- 기존 message preview에 최신 message_id, reply_completed, handoff_required를 함께 조회한다.
- 일반 답장 업무 = 최신 inbound + 미완료 + 현재 처리할 인계 없음. 인계는 모든 공고의 실제 disposition으로 판단.
- 인계와 공고별 후속 업무의 저장 상태는 변경하지 않는다. 다른 목적의 업무는 합치지 않는다.
- 관리자 완료 창은 수신 본문을 보여주고 답장 불필요/통화 해결을 기록한다. 새 메시지 ID이면 재확인 요청.
- 기존 pool_events에 정확한 message_id로 완료 기록. DB 스키마/모델 변경 없음.
- 완료 기록/인계 조회 실패는 0건으로 숨기지 않고 오류로 전달. 초안/인계가 남으면 완료 거절.
- 검수: exact ID/새 수신/다른 공고/오류 회귀; 홈+운영 가상 UI PC·좁은 화면; build.
- 롤백: 코드 revert. 추가 완료 이벤트는 이전 코드에서 무시됨.
