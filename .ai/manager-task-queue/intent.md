# 관리자 답장 업무 정리
goal: 답장이 필요 없는 수신을 문자 발송 없이 완료 처리하고, 인계와 답장 업무의 중복을 줄인다.
must:
  - 완료 대상은 관리자가 확인한 정확한 수신 메시지. 새 메시지는 다시 처리 대상으로 표시.
  - 실제 미해결 인계는 인계 큐에 보존. paused 자체를 완료/진행 근거로 쓰지 않는다.
  - 홈과 지원자 운영에서 같은 기준과 완료 기능 사용.
must_not: [문구만 보고 자동 종료, 자동 문자, AI 재개, 근무 확정, 신기범 일정 추측, 운영 데이터 검수용 변경]
success: 종료 처리 후 홈/운영 답장 건수가 일치하고 새 수신·다른 공고 미해결 업무는 보존된다.
