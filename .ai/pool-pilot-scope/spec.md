# Spec
- 인력풀 조건: 정기/백업/둘 다, 활동 지역, 가능 요일·시간, 차량, 백업 사전 연락 기간. 기존 정보와 별개 자기 신고 이벤트로 보관하며 관리자 대화에 표시한다.
- 공고가 없어도 개인 링크에서 저장/수정 가능. 채용·문자 동의·일시정지 상태는 변경하지 않는다. 조건을 자동 추론하거나 노출 필터를 변경하지 않는다.
- pilot 세션: 1~10명, 1~3개 실제 활성 공고, 1/4/24시간. 새 인입만 허용; cron/과거 인입/범위 밖 공고/기간 만료/환경 강제 중지/손상 값은 OFF.
- 시작 전 후보·수신거부·상태를 검증. 중단 후보를 재개하지 않는다. 새 관심 후보(null)는 선택된 공고에 한해 탐색 단계로 준비. 첫 문자 발송 없음.
- UI는 대상 이름·공고·기간 확인 후 시작, 즉시 중단 제공. 저장 결과와 자동 응대 가능 여부를 과장하지 않는다.
- 실패: 검증/조회 실패는 저장·발송 차단. AI 생성 후와 발송 직전 기존 fresh gate 유지. 롤백은 OFF 및 커밋 되돌리기; 과거 정보 이벤트 보존.
