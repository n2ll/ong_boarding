# 동작
- 수거는 해당 공고 body의 원문만 상담 fact로 제공. 배송시 맞수거/오후 재방문/반납을 구분하며 가방 날짜·완료시각 미기재를 추정하지 않는다. 미기재는 공고에 안내되지 않았다고 답한다.
- 일반 배송 첫날 안내에서 모든 배송에 반납 의무를 덧붙이는 문구 제거. 다른 공고나 공통 지식으로 조건을 보충하지 않는다.
- 공고의 단계별 총원은 유지하되 처리 필요는 기존 handoff disposition을 재사용한다. 완료·의도적 중지는 별도 표시하며 새 인계는 다시 노출한다.
- 중지 보관 건에서도 처리 완료 기록을 남길 수 있다. 기존 결과·메모 모달과 API 재사용, AI 재개 버튼은 노출하지 않는다.
- 모바일 후보 보드 마지막 버튼이 하단 내비게이션에 가리지 않도록 스크롤 여백을 확보한다.
# 실패·복구
- 문자 결과 불확실 시 재발송 없이 outbox/messages를 확인한다. 종료는 기존 paused를 유지한다.
- 상담 근거 불충분·검증 실패 시 기존 인계 동작 유지. 공고 근거로 확인 가능한 내용만 답한다.
- UI 분류는 읽기 전용으로 후보 상태를 쓰지 않는다. 문제 시 코드 revert, 기존 중지/종료 기록은 보존한다.
# 확인
공고별 수거 근거·시간 질문 회귀, 완료/신규 인계 분류, PC/390px 화면 및 중지 건 종료 저장, 통합 build/typecheck.
