# Spec
- 홈에 오늘(한국 시간)부터 7일의 일반 배송 충원 요약. 기존 staffing-date-board GET 재사용, 날짜순 3건 우선 표시/더 보기.
- 저장된 수요·명시적 확정 기준의 부족만 표시. 수요 미정은 별도 집계하고 충족으로 표현하지 않는다.
- 손상 기록, 같은 날짜 중복 확정, 수요 초과/운행 없는 날의 확정은 기록 확인으로 안내. 기록이 손상됐으면 부족 수치를 확정적으로 표시하지 않는다.
- 후보 확인은 /jobs?staffing_job=<id>&staffing_date=<date>로 해당 날짜 후보판을 연다. 잘못된/삭제된 공고 링크는 안내 후 목록 유지.
- 수요 미정/전체 확인은 /jobs?staffing_start=<date>로 7일 충원판을 펼친다. 기존 후속 연락 링크는 유지.
- 조회 실패·이전 범위 데이터는 빈 결과/충원 완료로 표시하지 않는다. 조회 기준 시각 표시, 재조회 제공, 포커스 복귀/기록 변경 시 갱신.
- 자동 발송·확정·수요 저장 없음. 모바일 390px 및 실제 Jobs 부모 화면에서 진입·닫기 검증.
