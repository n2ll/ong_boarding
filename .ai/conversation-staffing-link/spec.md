# 동작
- 지원자 상세의 선택된 일반 배송 공고에 연락·메모 / 선탑 일정 / 참여·결과 링크를 표시한다. 다른 공고로 자동 대체하지 않는다.
- 공고 화면에서 공고·후보를 최신 조회하고 기존 편집기를 해당 목적에 맞춰 연다.
- 서버가 기록 없음을 명시한 후보만 새 기록 입력을 허용한다. 누락·손상·삭제는 빈 기록으로 대체하지 않는다. 기존 홈 후속 연락 링크는 저장 기록이 있어야 한다.
- 기존 미저장 상세 입력의 페이지 이동 가드와 저장 API의 동시 수정 보호를 재사용한다.
- 인력풀 선탑 기록에는 별도 이력임을 안내한다. 저장·AI 응대 정책은 변경하지 않는다.
