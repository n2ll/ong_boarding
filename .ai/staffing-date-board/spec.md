# 계약
- API: GET /api/admin/staffing-date-board?start=YYYY-MM-DD&end=YYYY-MM-DD, 관리자 전용, 1~7일.
- 모집 중인 일반 배송 공고만 포함. 비마트·시스템·명시된 검수 공고 제외. 전체 페이지 조회 성공 시만 집계.
- 최신 연결 후보의 최신 staffing_preparation만 집계. 중단 후보 제외. 손상 최신은 경고하고 옛 기록으로 대체하지 않는다.
- 날짜 confirmation?: unconfirmed|confirmed. 생략은 미확정. available+primary_candidate만 confirmed 허용.
- confirmed: 날짜별 명시 확정. reserve: 가능+예비. primary: 가능+본담당(확정 포함).
- target: 양의 정수 capacity. 부족=max(0,target-confirmed). 목표 미정은 null. 모든 날짜에 공고 모집인원 기준임을 화면에 표시.
- 같은 사람이 같은 날 다른 일반 라인에도 확정되면 시간 확인 경고. 시간 충돌/불가능으로 단정하지 않는다.
- 기존 또는 요청 날짜에 확정이 있으면 confirmation_version:1 없이는 409. 날짜 삭제도 포함. 기존 참여 이력/CAS/멱등성 유지.
- 새 날짜 확정은 중단 후보·마감 공고에서 차단한다. 기존 확정 유지·메모 수정·취소는 허용한다.
- 확정·취소 변경은 날짜를 보여주며 저장 직전 확인. 저장은 SMS/AI/stage를 변경하지 않는다.
- 화면: 접을 수 있는 충원판, 기간 선택, 목표/확정/예비/부족, 셀에서 기존 배차 준비의 날짜로 이동. 실패 시 지난 수치 숨김/재조회.
- PC·390px 모바일에서 읽기와 저장 가능. 표 대신 좁은 화면에 카드 배치.
# 실패·복구
- 읽기 실패 503, 빈자리 없음으로 해석 금지. 잘못된 기간 400.
- 기존 append-only pool_events 재사용. 스키마 변경 없음. 확정 취소도 새 이력에 보존.
- 롤백 시 확정 기능 UI를 숨기되 구버전 저장이 날짜별 확정을 지우지 않도록 API 보호 유지.
